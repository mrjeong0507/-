2026년 제전단가 가중치 정산 방식

가중치(초기값)

  • 상급: 260,000원 → 1.13
  • 중급: 250,000원 → 1.09
  • 관리자: 230,000원 → 1.00

배분 공식

개인 배분액 = W × (개인 가중치 ÷ 전체 가중치 합)

예시

26-001 하우징 W = 2,000,000원

가중치 합 = 4.31점

  • 상급 A → 524,350원
  • 중급 B → 505,800원
  • 중급 C → 505,800원
  • 관리자 D → 463,200원

✔ 숙련도·품질·속도 차이가 정직하게 반영됨

✔ 회사는 물량(Q)만큼만 비용 발생 → 손실 제거

용접사 이탈 방지 전략(핵심)

✅ 1) 물량 부족해도 "회사사유 손실"은 보상
  • 자재 지연, 도면 오류, 급단납기는 전부 인센티브 지급
  • 회사 리스크를 용접사에게 떠넘기지 않음
✅ 2) 2027년 소사장제 전환 시 더 높은 단가 제공
  • "1년만 버티면 더 많이 벌 수 있다"는 미래 확실성 제공
✅ 3) 대기 없음 → 조기퇴근 및 시간 활용
  • 물량이 적어도 스트레스 없음
  • "괜히 붙잡아 두는 회사"가 아님
✅ 4) 용접사의 직접 영업 허용(매우 중요)
  • 회사 물량이 적어서 벌 기회가 없다는 문제를
  • → "스스로 영업해서 물량 확보 가능"한 구조로 바꿈.
  • 영업부와 협의하여 단가 산정 후
  • → 해당 오더를 확보한 용접사에게 추가 인센티브 지급
  • 외부 수익 창출을 용접사가 주체적으로 할 수 있음
  • 회사도 물량 증가로 Win-Win

용접사 직접 영업 인센티브 방식

운영 방식

  1. 용접사가 지인·파트너·기존 고객 접촉
  2. 제작 가능 제품(하우징·탱크 등) 수주 의향 확인
  3. 생산팀 + 영업팀 함께 단가 검토
  4. 회사 정책에 맞을 경우
  5. 오더 발행 후 제작 진행
  6. 수주한 용접사에게 인센티브 지급

인센티브 방식

  • 수주금액의 일정 비율(예: 3~5%)
  • 또는 제품 1대당 고정 인센티브(예: 30~50만 원)
  • 제전단가 정산 외 별도 지급
  • 영업부 기준과 충돌하지 않도록 협의

효과

  • 물량 부족 문제를 "용접사가 직접 해결할 수 있는 구조"로 전환
  • 용접사의 수입 불안 완화
  • 회사는 추가 오더 확보 → 매출 증가
